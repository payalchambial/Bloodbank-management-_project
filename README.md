# Blood Bank Management System

A Python-based Blood Bank Management System designed to manage blood donors, blood groups, donor eligibility, and donation records efficiently.

## Technologies Used
- Python
- Pandas
- CSV
- Streamlit

## Features
- Donor registration and management
- Blood group management
- Donor eligibility checking
- Blood donation record management
- Search and manage donor information
- CSV-based data storage

## Donor Eligibility
- Age: 18–65 years
- Minimum 90-day gap between donations

## Purpose
The project helps organize donor information and makes blood bank management easier and more efficient.

## Project Type
Blood Bank Management System using Python
